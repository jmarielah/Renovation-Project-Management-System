<h1>Renovation Project Management System</h1>
<hr>
<p>A system that aims to make project management more convenient for small-scale interior design businesses. 
  It was developed using HTML and CSS, along with frameworks such as Bootstrap. This system
includes features, such as databases and interfaces, that will decrease inefficiencies in data
recording and project monitoring. Moreover, it aims to solve a recurring problem brought by
incidental expenses and time-consuming processes associated with material costing. Once
implemented, the system will assist users through the renovation aspect of each project by
providing access to digitalized data organization methods.</p>
